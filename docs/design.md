# Визуальные направления D3

Направления предложены 05.11.2026. Владелец выбрал A, «ПОЛДЕНЬ», после просмотра прототипа. B сохранено ниже как историческая альтернатива и дальше не разрабатывается.

## A. ПОЛДЕНЬ — солнечная студия (выбрано)

Кремовая бумага `#f3f0e6`, кобальт `#233bb9`, мандариновый `#edb153`, грушевый `#c4d09b`, вишнёвый `#dfa3ac`. Плотный гротеск и контрастный курсив Georgia. Нативные системные шрифты; загружаемых шрифтов нет.

На первом экране слева крупная фраза и действие, справа — авторская предметная сцена. Большой солнечный диск, наклон банки, металлический ободок, небольшой конденсат, волны на упаковке. Цвет и рисунок меняются вместе со вкусом. Далее — текстовый разворот: сочетание, характер, демонстрационный состав. Покупка объясняет отсутствие реального товара.

На телефоне порядок вертикальный: название и CTA → крупный предмет → выбор вкуса. Упаковка читается в портретном формате; CTA доступен до сцены. Диапазон 460–700 px после обнаруженного наложения тоже использует вертикальную композицию.

Предполагаемая польза приёма: посетитель различает вкусы через упаковку и описание, а выбранный вкус сохраняется в следующем шаге. Это гипотеза подачи, а не измеренная конверсия.

## B. ТИШЕ — ботанический атлас

Тёмный хвойный фон, светлая бумага, медные акценты. Строгие засечки, тонкие рисунки растений, спокойная асимметрия. Предмет в центре как образец коллекции, рядом заметки об ингредиентах. На телефоне — вертикальный лист атласа. Медиаприём: короткое раскрытие пары ингредиентов вокруг упаковки при смене вкуса.

Более камерный и созерцательный характер. При выборе B потребуется другой дизайн упаковки и сцены; простая смена цветов A не заменит эту концепцию.

## Медиаприём и альтернативы

Авторские SVG + CSS. Небольшой параллакс при указателе мыши, постановочный подброс банки по кнопке (0,85 с) и короткая смена вкуса (0,5 с). Добавлена запрошенная владельцем бегущая синяя лента; автозвука нет. Клавиатура запускает тот же приём кнопкой, мышь не обязательна.

- Reduced motion: CSS отменяет анимации, JS не запускает подброс/параллакс; остаётся статичная банка.
- Без JS: статичная банка мандарина, все вкусы и составы в HTML, обычные якорные ссылки; кнопка анимации скрыта.
- Без WebGL/видео: основной режим, эти технологии не используются.
- При ошибке SVG: обработчик показывает текстовую замену; описания и действие не зависят от картинки. Без JS сохраняется alt изображения.
- При медленной сети: текст и CTA не ожидают тяжёлую сцену; выбранное изображение грузится отдельно, остальные SVG запрашиваются при выборе.

Предмет создан специально для прототипа, это не чужой мокап. Но качество упаковки/сцены ещё должно быть оценено владельцем и независимым ревьюером; статус «визуальный флагман готов» не присваивается.

## Бегущая лента R2

Две равные копии текстовой группы, движение CSS transform до −50%, скорость 28 CSS px/с. ResizeObserver обновляет только длительность при изменении ширины; покадрового JS нет. Компактная кнопка справа ставит на паузу и продолжает с той же позиции, Enter/Space работают. Скрытая вкладка приостанавливает CSS-анимацию.

Один текст девиза доступен скринридеру; движущиеся копии aria-hidden, без aria-live. Без JS кнопка скрыта и лента статична. При reduced motion CSS отменяет анимацию, JS скрывает управление; изменение настройки обрабатывается во время просмотра. Фактическая глубина проверки и ограничения интерфейса браузера указаны в acceptance.md.
