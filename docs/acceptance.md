# Авторская проверка D3 — R2

Дата: 05.11.2026. Направление «ПОЛДЕНЬ» выбрано владельцем. Завершены реализация ленты и N9, выполнены доступные авторские проверки. **Это самоотчёт исполнителя, не независимая приёмка.** Ограничения среды ниже требуют отдельного повторения ревьюером.

## Срез и среда

Идентификатор: `d3-polden-r2`. Node 22.23.4, npm 10.9.9, macOS. Реальный рендер — встроенный браузер Codex через CUA; его User-Agent сообщает Chrome/156.0.0.0, Mac OS X 10_15_7. Это строка UA, не независимо проверенная версия бинарника. Установленный Chrome 157.0.8103.38 обнаружен, но отдельный управляемый браузер в доступном интерфейсе отсутствовал. Safari, Firefox, реальные телефоны и VoiceOver не проверялись.

`evidence/build-manifest.json` содержит SHA-256 семи публичных файлов. `evidence/source-manifest.json` идентифицирует передаваемый комплект R2. Исключены сам manifest, временные/резервные каталоги сборки, локальные резервные копии содержания, системные файлы и будущий каталог ревьюера. Старый manifest прототипа сохранён в `evidence/prototype-01/` как история; он не описывает текущие исходники. Скриншоты и доказательства вне r2 относятся к этапу прототипа, кроме актуальных build/source manifest и transport.json.

## Производительность

Профиль: реальный браузер, 390×844 CSS px, no-store, первоначальная навигация без кэшированных тел; сервер задерживает **каждый ответ** на 150 мс + gzip-размер / 163 840 байт/с. Это не общая ограниченная полоса соединения, не имитация конкретного телефона и не замедление CPU. Инструментальная панель есть только в локальном preview, не в dist.

- LCP: **424 мс**; CLS: **0**. Наблюдение через PerformanceObserver, `r2/slow-390-initial.json`.
- Начально передано **13 553 Б** по browser Performance entries: документ и ресурсы страницы; здесь favicon запрошен дважды. Локальный измерительный скрипт исключён. `transferSize` — браузерная оценка HTTP-ответов, не пакетный захват.
- После смены вкусов, клавиатурных паузы/продолжения и запуска сцены максимальная длительность зарегистрированного события **56 мс**; `r2/slow-390-interactions.json`. Это Event Timing, **не полевой INP**.
- Отдельный фактический HTTP/1.1 замер Node по loopback: **11 485 Б gzip-тел**, **12 677 Б ответов с заголовками**. JS **1 923 Б gzip**, стороннего JS нет; `evidence/transport.json`.
- Все медиа — SVG или ограниченный PNG, видео/WebGL нет. Варианты загружаются при выборе.

В описанном профиле исходного содержания бюджеты 1 МБ / 100 КБ JS gzip / 5 МБ тяжёлого медиа выдержаны с запасом; LCP <2,5 с и CLS <0,1. Это лабораторный локальный результат, не гарантия публичного размещения или полевые данные.

## Ограничения, которые не засчитаны как пройденные

1. **Настоящий browser zoom 200%.** Доступен viewport, но нет надёжного управления zoom; клавиатурный shortcut не изменил наблюдаемую геометрию. Ширина 360/390 не выдана за проверку масштаба.
2. **Системный reduced motion и его смена в браузере.** Интерфейс не предоставляет эмуляцию media preference. Реальный app.js проверен в Node VM с DOM/matchMedia-заглушками: начальное уменьшенное движение, смена настройки, сохранение ручной паузы, скрытая вкладка. CSS содержит безусловную отмену анимаций/переходов внутри media query. Это проверка ветвей кода, не браузерный прогон системной настройки.
3. **Другие движки, физическое касание, VoiceOver.** Не доступны в проверенном интерфейсе; не заявлены проверенными.
4. Публичная среда, внешние ссылки магазинов, релиз и внешний smoke отсутствуют по границам задачи.

## Повторение и независимая приёмка

Команды запуска/проверки — README; N9 — content-editing.md. Проверки ленты доступны в панели `/?audit=1`; после нажатия «Наблюдать два цикла» дождаться двух событий, в том числе проверить ручную паузу. На 1440 один цикл ≈51,43 с, на 390 ≈22,86 с.

Сначала сверить source-manifest (`node tools/manifest.mjs`, режим без записи), затем читать код, воспроизвести сборку/N3/N9, посмотреть рендер и проверить перечисленные ограничения в доступной среде ревьюера. Его доказательства — отдельный `docs/review-coordinator/`. Исполнитель этот каталог не заполнял и общий хэндоф не менял. После фиксации R2 запись в переданные файлы прекращена до замечаний.
