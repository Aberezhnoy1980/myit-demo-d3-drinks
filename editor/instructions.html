От правки до проверенной страницы

Редактор работает только с локальным содержанием. Публичная страница не предоставляет доступа к редактированию.

  1. Измените поля. Для иллюстрации выберите PNG/JPEG/WebP до 4 МБ; редактор подготовит компактный PNG.
  2. Нажмите «Обновить предпросмотр». Посмотрите ширины 390 и 1440 px, все вкусы и «Где купить».
  3. Нажмите «Подготовить экспорт», затем «Скачать polden-content.json». Проверьте, что файл появился в выбранной папке.
  4. Откройте терминал в папке проекта. Выполните команды ниже, заменив путь в кавычках на путь к скачанному файлу. Код редактировать не требуется.
cd /Users/alex/myit/demo/Landing/d3-drinks/
fnm exec --using=v22.23.4 -- node tools/apply-content.mjs "/полный/путь/polden-content.json"
fnm exec --using=v22.23.4 -- node tools/build.mjs

Обе команды повторно проверяют данные. Если есть ошибка, прочитайте сообщение и исправьте файл через редактор. При отказе проверки прежняя сборка сохраняется.

Откройте локальную страницу и обновите вкладку. Если preview ещё не запущен:

fnm exec --using=v22.23.4 -- npm run preview

Откат

Команда применения напечатает путь резервной копии. Для отката передайте этот путь той же команде apply-content, затем повторите build. Исходная авторская версия также сохранена отдельно:

fnm exec --using=v22.23.4 -- node tools/apply-content.mjs content/original.json
fnm exec --using=v22.23.4 -- node tools/build.mjs

Что дальше

Сборка не публикует сайт. Для выпуска передайте проверенный каталог dist ответственному за размещение; разрешение владельца на публикацию требуется отдельно. Названия вкусов, макет, магазины и торговые ссылки этим редактором не меняются. Загрузка картинки заменяет всю иллюстрацию, а не текст на этикетке.
