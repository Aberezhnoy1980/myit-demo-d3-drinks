# ПОЛДЕНЬ — локальное демо D3

Вымышленная коллекция напитков для портфолио myit. Направление A выбрано владельцем 05.11.2026. Реализованы сценарий выбора вкуса N3, бегущая лента и ограниченный редактор содержания N9. Срез R2 передаётся на независимую приёмку; это не статус «принято» и не публичный выпуск.

## Запуск

Проверено на macOS, Node **22.23.4**, npm **10.9.9**. Зависимостей нет; установка и lock-файл не нужны. Из этой папки:

```sh
fnm exec --using=v22.23.4 -- node tools/build.mjs
fnm exec --using=v22.23.4 -- npm run preview
```

- [Страница](http://127.0.0.1:4333/)
- [Та же сборка под префиксом](http://127.0.0.1:4333/portfolio/d3/)
- [Мастерская содержания N9](http://127.0.0.1:4333/__editor__/)
- [Инструкция применения и отката](http://127.0.0.1:4333/__editor__/instructions.html)

Preview слушает только 127.0.0.1, принимает GET/HEAD, использует gzip и no-store. Остановка — Ctrl+C в терминале сервера. Если нужный Node уже выбран в PATH, команды можно запускать без оболочки fnm.

## Проверить

Выберите вкус → сравните упаковку и описание → нажмите «Встряхнуть день» → перейдите к «Где купить». Там сохранён выбранный вкус и объяснено отсутствие продаж. Лента движется справа налево; её кнопка останавливает и продолжает движение, включая Enter/Space. Без JS и при reduced motion она статична.

```sh
fnm exec --using=v22.23.4 -- npm test
fnm exec --using=v22.23.4 -- node tools/measure.mjs
```

Тесты используют встроенный node:test и временную копию внутри D3. measure требует запущенного preview. Полные условия, методы и ограничения: [docs/acceptance.md](docs/acceptance.md).

Локальные проверочные URL (не входят в dist): `/?audit=1` — панель LCP/CLS, событий и двух циклов; `/__slow__/?audit=slow` — задержка ответов; `/?audit=no-js` — запрет выполнения скриптов через CSP; `/?audit=missing-media` — намеренные ошибки изображений.

## Содержание и границы

Редактор меняет заголовок, описание первого экрана, тексты трёх вкусов и иллюстрации. Он показывает предпросмотр и экспортирует проверенный JSON. Применение — отдельная локальная команда с резервной копией; затем build. Подробности: [docs/content-editing.md](docs/content-editing.md). Это ограниченный редактор, не CMS. Он не меняет магазины, макет и названия вкусов.

- `src/` — шаблон, CSS/JS и авторская упаковка SVG.
- `content/` — рабочие данные, исходная версия и резервные копии.
- `lib/` — общая проверка и отрисовка содержания для редактора и сборки.
- `editor/` — локальная мастерская, не включаемая в публичную сборку.
- `tools/`, `tests/` — локальные инструменты и проверки без зависимостей.
- `dist/` — только статическая страница и её ресурсы; после отката 7 файлов.
- `docs/evidence/r2/`, `docs/screenshots/r2/` — доказательства текущего этапа; старые файлы вне r2 относятся к прототипу.

Сборка сначала проверяет всё содержание, затем готовит отдельный каталог и заменяет dist. При ошибке проверки рабочий dist сохраняется. Для отката содержания примените напечатанную резервную копию или `content/original.json`, затем повторите build. Временные `.build-stage`/`.build-previous` — только производные сборки.

Нет реальных продаж, контактов, форм, аналитики и внешних интеграций. Git, установки, платные вызовы и публикация не выполнялись. Возможное размещение — только содержимое dist после независимой приёмки и отдельного разрешения владельца. Целевая площадка и внешний smoke не проверялись; `noindex, nofollow` сохранены.

## Идентификация среза

Перед независимым повторением: `fnm exec --using=v22.23.4 -- node tools/manifest.mjs` — только сверка файлов без записи. После согласованных исправлений исполнитель может сформировать новый manifest ключом `--write`; текущий R2 без замечаний не переписывать.
